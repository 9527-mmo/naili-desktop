# 奶栗的打工日记 · Mac 桌面宠物

这是可以在 Mac 上构建的原生桌面程序项目。支持 macOS 12 或更新系统，以及 Apple Silicon（包括 M1 Max）和 Intel Mac。构建时自动匹配当前 Mac 架构，不需要 Python、Node.js、付费接口或联网运行。

## 第一次运行

1. 解压整个文件夹，不要只取出其中一个文件。
2. 双击 `Build-and-Run.command`。
3. 如果提示安装 Apple 命令行开发工具，按系统提示安装；完成后再次双击脚本。只需首次安装。
4. 构建完成后会自动打开奶栗。生成的程序位于 `dist/Naili.app`，可以拖入“应用程序”，以后直接双击启动。

如果双击脚本无法打开：打开“终端”，输入 `bash `（末尾一个空格），把 `Build-and-Run.command` 拖入终端窗口，再按回车。不要粘贴未知脚本。这个脚本仅构建当前文件夹内的代码、进行本地临时签名并打开生成的应用。

如果 macOS 拦截打开，按系统“隐私与安全性”的提示处理这个你刚生成的应用，无需关闭系统安全保护。此项目未经过 Apple 开发者证书签名和公证。

## 使用

- 点击齿轮：设置月薪、上班和下班时间、工作日、午休、计薪模式、窗口大小、置顶、跟随强度和活跃程度。
- 拖动“奶栗的打工日记”标题：移动窗口。
- 点击奶栗：互动和欢跳。
- 点击 ▷：顺序预览21组动作；再次点击退出预览。
- 点击 −：隐藏到菜单栏。菜单栏兔子图标可以恢复、打开设置或退出。
- 菜单栏“移回当前屏幕”：窗口跑到其他显示器时找回。
- 可在 macOS“登录项”中手动加入构建好的 `Naili.app`，让它登录后启动。

## 跟随行为

系统鼠标在当前所在显示器上的横向位置，映射到宠物平台的左右范围。采用死区、平滑加减速和约±21像素随机偏移；奶栗可以在附近自由活动。短动作会先完成，趴睡时大幅移动会先唤醒，再追随。跟随强度设为0时停留在原区域做随机动作。

21组动作使用已确认预览中的84个关键帧：慢走、小跑、转身、抖耳歪头、洗脸、啃萝卜、伸懒腰、翻滚、打盹、醒来、庆祝、探头看收入。它们是第一版像素关键帧动画，尚未扩充为逐动作高帧数精修动画。

## 计时与计薪

- 工作模式：月薪 ÷ 本月计划有效工作毫秒数 × 已经过的有效工作毫秒数；午休可排除。
- 全天模式：月薪 ÷ 当前自然月实际总毫秒数 × 已经过的毫秒数。
- 今日收入在本地午夜归零，本月累计在自然月首日归零。
- “工作日”按班次开始日期计算；下班时间早于上班时间视为跨夜班。
- 下班后显示距离下一班次下班的时间。到点时如果应用正在运行且没有长时间休眠，会播放庆祝动画。
- 唤醒后以系统时间重新计算，不依靠后台计数次数；不会强制电脑24小时亮屏。
- 收入仅为估算，不处理税费、请假、奖金和法定节假日调休。当前排班设置用于重算整个月，不保存历史版本；修改月薪或排班会同步改变本月估算。
- 所有设置只保存在本机。无网络请求、账号或云端上传。

## 项目与测试

`main.swift`：Mac透明窗口、菜单栏、全屏鼠标坐标、拖动与本地设置。
`web/`：界面、动画、计薪计算及图片资源。双击其中的 `index.html` 可先预览；浏览器只能跟随页面内鼠标，不具备原生桌面能力。
`tests/engine.test.cjs`：可选开发者计算测试，用 Node.js 运行：`node tests/engine.test.cjs`。

开发者可选：安装 Node.js 后运行 `npm test`，执行计算与DOM交互测试；正常使用奶栗不需要这些依赖。

已在制作环境验证：JS语法、shell脚本语法、计薪逻辑（午休、跨夜、周末、跨月、夏令时）、DOM模拟下的鼠标左右映射、设置保存、活动边界和21组动画切换。未完成浏览器截图验收。当前制作环境为Linux，未运行Swift编译或macOS窗口测试；首次在Mac构建可能需要根据实际系统反馈调整。

## 1.1 动画优化版（2026-11-10）

先双击 `Preview.html` 查看可交互预览，点击 ▷ 轮播21组动作。`Animation-preview.gif` 为25fps的播放节奏示例。Mac首次构建仍使用 `Build-and-Run.command`；升级前请从菜单栏退出旧版奶栗。

本次已替换为最近确认的像素造型，并接入9组进食动作，共21组84张关键图。

- 动作不再平均分配成每秒1～2张图：步行基准每125ms换姿势、小跑每90ms、咀嚼变化段约100～130ms，同时保留合理停顿。步频会随移动速度变化。
- 位置使用requestAnimationFrame随显示刷新更新，通过transform移动；原生鼠标采样目标60Hz。真实帧率受设备和系统调度影响，未实测Mac帧率。
- 预加载、解码并常驻所有图帧，切换可见性，避免每帧重新赋值大型图片数据。
- 平滑加减速、反向前停步转身、睡醒后跟随、进食后舔嘴/擦脸；点击互动等待当前短动作完成。
- 每组仍只有4张独立关键姿势，使用时间编排与程序位移，不是已绘制24/60张中间姿势，也未使用重影交叉淡化。后续精修还需绘制中间姿势。

验证：工资逻辑回归；21组时间轴；30/60/120Hz模拟下移动一致性；转向边界及睡眠唤醒；播放器模拟中的84张挂载图、动作切换与跟随。头部图帧已做透明边缘检查。完整浏览器渲染测试在此环境因进程限制未能执行；未进行macOS编译与实机验证。

测试无第三方依赖，安装Node.js后可直接 `npm test`。浏览器预览只能读取页面内鼠标，原生Mac程序才读取全屏位置。
