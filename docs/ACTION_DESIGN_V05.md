# 奶栗动作设计 v0.5

## 角色基准
以 `characters/naili/DESIGN_LOCK.md` 为准：8-bit 像素画风、竖耳、额头白带、薄白色环颈毛、**尾巴和屁股毛与体毛同色**。不以示意图替换锁定造型。

## 行为优先级
人工互动 > 进食/睡眠关键阶段 > 移动 > 自主微动作 > 待机。

## 动作阶段
| 动作 | 准备 | 主体 | 收尾 |
| --- | --- | --- | --- |
| walk | 观察/转向 200–450ms | 四足交替步伐，步速匹配位移 | 逐渐减速，站稳 300–600ms |
| run | 压低身体 180ms | 蹬腿腾空、落地缓冲 | 小幅回弹 300ms |
| feed | 嗅闻 500–900ms | 前爪扶住、咬取、咀嚼 1800–3000ms | 舔嘴、抬头 400–700ms |
| sleep | 收爪趴下 800–1300ms | 闭眼呼吸 7–18s | 伸展、抖耳 700–1200ms |
| curious | 抬头 250ms | 轻歪头、转耳 | 缓慢复位 300ms |
| pet | 放松、闭眼 | 小幅耳动、低头 | 缓慢恢复 |
| play | 蓄力 | 小跳、落地 | 缓冲站稳 |

## 防机械循环
- 待机至少约 3.2 秒；自主动作通常间隔 4.5–10.5 秒或更久
- 进食至少约 3 秒，睡眠至少约 7 秒；人为操作结束后保留冷却期
- 不连续重复同一种明显动作；轻微眨眼、耳尖、呼吸可独立叠加
- 移动时禁止突发睡觉，停稳后至少 1 秒才选择新的自主动作
- 行走步频应由实际位移速度驱动，而非单纯固定循环

## 帧率
目标屏幕刷新 60 FPS（requestAnimationFrame）；像素精灵关键帧可低于 60 张/秒，配合时钟与位移平滑。不要使用模糊插值破坏像素边缘。

## 当前实现范围
行为调度模块与规范已写入；精修逐帧素材、移动步频同步、自然动作过渡仍待实现与实机测试。
