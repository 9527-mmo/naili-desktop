# 主动投喂 v0.7

## 已实现的原型流程
1. 在设置中启用「主动投喂」（默认关闭，保存在 settings.json）。
2. 在奶栗自身窗口内双击鼠标右键，弹出食物选择面板。
3. 选择八种食物之一并确认。
4. 暂停普通跟随/自由游走，保存原始宠物窗口坐标，暂时放宽移动边界，朝食物位置移动。
5. 到达后进入抓取状态，随后按原路逻辑返回保存位置。
6. 回到原位置后播放进食动作，完成后恢复原有活动模式。原本的 fullScreen 设置不会改变。

## 重要限制
- 当前右键双击仅能监听宠物 Electron 窗口内部，**不是系统全局监听**。
- 在其他应用/桌面任意位置双击右键需要 macOS 原生事件监听或可靠的 native hook，以及辅助功能/输入监控权限；Electron 标准 API 无法实现。尚未集成或测试。
- 临时全屏指临时放宽移动坐标，不是铺满屏幕的透明窗口。
- 抢夺、叼食和返回动作当前由状态与移动控制原型表现，正式像素逐帧素材待制作。
- 多显示器跨屏、系统菜单栏/Dock、窗口碰撞、用户中途取消、异常恢复尚待测试与完善。
