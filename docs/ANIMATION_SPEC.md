# 奶栗动画规范 v0.2

## 角色锁定
- 焦糖棕到浅奶茶色渐变毛发，额头白带，奶白围脖（不应过厚）
- 蓬松脸颊；尾巴与身体同色；不改变兔子基本脸型和眼睛
- 当前 Canvas 仅为程序化角色占位原型，最终精修立绘及逐帧素材仍待制作

## 当前交互
| 操作 | 行为 |
| --- | --- |
| 单击兔子 | 抚摸、爱心 |
| 双击兔子 | 喂食 |
| 🥕按钮 | 轮换胡萝卜、青菜、苹果、干草 |
| ✨按钮 | 蹦跳 |
| 🌙按钮 | 睡觉 |
| 拖动兔子 | 移动窗口 |
| ×按钮 | 退出 |

## 流畅度策略
- Canvas 使用 requestAnimationFrame，与屏幕刷新节奏同步
- 不用固定帧间隔 setInterval，避免不必要的卡顿
- 尊重系统 prefers-reduced-motion，关闭大幅位移和周期性摇摆
- 下一阶段：使用预渲染纹理图集、脏矩形优化及帧时间监测

## 验收要求
- Mac M1 Max 32GB 上进行实际运行与 CPU 占用测试
- 不允许把程序化原型称为最终美术素材
- 新素材必须逐一核对耳朵、脸颊、围脖、额头白带、尾巴毛色
