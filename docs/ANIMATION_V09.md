# 奶栗动画 v0.9 迭代记录

## 本轮已完成（Canvas 临时动画）
- 抢食：接近目标后先停下，低头动作与耳朵变化，抓取阶段约 1.1 秒
- 叼食：返回途中食物保持在嘴部附近，不再凭空消失
- 咀嚼：食物在嘴边随进食阶段逐渐缩小，加入嘴部节奏
- 收尾：进食末尾短暂伸舌舔嘴
- 如厕：蹲坐阶段轻微压低身体
- 步态：走、跑、叼食三种运动状态分别处理
- 修复：原先只在 feed 模式绘制食物，导致 chew/carry 状态食物消失
- 修复：主进程接受新增动作状态

## 动作演出建议（正式像素帧待制作）

| --- | --- | ---: |
| run | 前爪蓄力、身体前探、蹬地、腾空、落地 | 10 |
