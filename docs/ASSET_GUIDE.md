# 奶栗精修素材接入指南

## 现状
当前程序使用 Canvas 绘制的占位兔子。角色精修图、透明逐帧 PNG 尚未导入仓库。
本阶段新增素材目录结构和验收标准，**不把概念图当成可直接播放的透明逐帧素材**。

## 目录约定
```
assets/naili/
  idle/       # 8 帧，眨眼、呼吸、耳朵轻动
  walk/       # 8 帧，步行循环
  eat/        # carrot, leaf, apple, hay 各 8 帧
  sleep/      # 8 帧，趴卧、闭眼、呼吸
  other/      # 抚摸、蹦跳、心情等
```
每组使用 `000.png` 起始的连续编号。推荐每帧 720×780 RGBA PNG，透明背景；相同动作组角色锚点一致，避免抖动。

## 美术验收
- 焦糖棕到奶茶色毛发，额头白带、奶白围脖
- 蓬松脸颊，围脖不过度膨胀
- 尾巴与身体同色
- 耳朵、眼睛、脸型和体态在所有帧保持一致
- 保持与用户确认的最终造型一致，未经确认不替换主体设计

## 接入步骤
1. 完成逐帧 PNG 资产并审核角色一致性
2. 添加资源清单 JSON 和预加载器
3. 使用同一时钟驱动帧序列，失败时回退 Canvas 占位角色
4. macOS M1 Max 实测帧率、CPU 和拖动窗口流畅度
