# 倒计时面板 v2 · 温暖像素木屋风（紧凑版）

## 实现
- 独立透明 Electron 窗口：420 × 280（内容区 406 × 260）。
- HTML/CSS 绘制像素木质外框、复古数字牌、奶油色信息层、进度条、双收入卡片；不是将效果图直接作为静态背景。
- 使用系统本地时间，每秒更新倒计时和收入；工作时倒数至下班，非工作时倒数至下次上班。
- 点击齿轮修改上/下班时间、月薪和计薪模式；设置通过原有 Electron IPC 持久化。
- 点击「−」隐藏面板；奶栗设置中的「显示倒计时与工资面板」可重新打开。
- 鼠标拖动面板主体可以移动窗口。

## 计薪说明
- 工作时间模式假设每天同一班次、按当月自然日平均分配月薪；未纳入周末/节假日/休息日/税费/考勤等。
- 24 小时均摊模式以当前自然月总毫秒数平均分配。
- 夜班跨日倒计时已支持；跨月薪资和夜班日收入仍需更严谨的业务验收。

## 本地运行与验收
```bash
npm install
npm start
```
请在 macOS 上检查 Retina 像素边缘、拖动、隐藏与恢复、时间设置持久化、夜班时间、系统休眠唤醒和多显示器窗口位置。

## 当前限制
- 这版为可运行代码，尚未进行 macOS 实机验收。
- 顶部预留奶栗互动区域，但「奶栗在面板上方行走、趴下和离开返回」的跨窗口联动尚未实现。
- 角色图标是界面占位符，正式 Gen 1 角色应使用经过审核的像素素材。
