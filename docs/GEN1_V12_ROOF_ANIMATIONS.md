# Gen 1 v1.2 面板互动动作：代码接入说明

已在 `src/animation-controller.js` 注册 `roofSit`、`roofLie`、`roofStretch`、`roofWake` 四种状态。渲染器依据主进程的 `resting` / `returning` / `away` 通知进行坐下 → 趴卧 → 休眠 → 伸懒腰 → 坐下循环；点击奶栗会打断休息并播放起身过渡。

**素材状态**：此前生成的 v1.2 图片是整体设计审核图，尚未逐帧切分为统一画布、透明背景、经验证的 PNG 序列。因此本次提交的是可运行的行为逻辑及 Canvas 过渡姿态，不是正式像素素材包。若以后提供正式透明 PNG，请沿现有 Gen 1 motion loader 接入，不要直接把审核图裁剪成带文字/背景的帧。

**测试重点**：Mac 实机需检查状态切换时是否闪跳、投喂和拖拽是否打断自动睡觉、离开面板是否停止顶部动作、动作脚底是否贴合木框、帧率及 CPU 使用率。尚未完成实机验证。
