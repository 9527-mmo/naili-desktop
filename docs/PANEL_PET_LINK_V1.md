# 奶栗 Gen 1 × 倒计时面板顶部联动（第一阶段）

## 已接入
- 当面板显示、未开启全屏活动、未开启鼠标跟随时，奶栗的默认活动目标改为倒计时面板上沿。
- 基于面板窗口坐标与奶栗透明画布脚部锚点（约画布高度 88%）计算站立位置。
- 每隔约 7–14.5 秒在顶部左右约 35px 的范围内选择新目标，短暂停留，使用现有移动状态驱动行走动画。
- 拖动面板后，奶栗逐步跟向新位置。
- 鼠标跟随、主动投喂、如厕和手动拖拽仍优先于回家行为；隐藏面板或开启全屏活动后沿用原自由活动逻辑。

## 限制与下一阶段
- 当前为跨窗口**位置联动原型**，不是精确的碰撞/边缘行走系统；脚底锚点需根据 Gen 1 PNG 真正可见区域实机微调。
- macOS 多显示器、屏幕顶部边界和不同缩放比例需实测。
- 尚未完成面板顶部专属的趴睡/坐姿、离开与返回路径规划。
- 没有在 Mac 实机验收，不应标记为测试通过。

## 验证
```bash
git pull
npm install
npm start
```
1. 保持「显示倒计时与工资面板」开启，关闭全屏活动和跟随鼠标，观察奶栗是否回到面板顶部。
2. 拖动面板，检查奶栗是否平滑跟随。
3. 开启全屏活动，检查是否恢复自由探索；关闭后返回面板。
4. 主动投喂后观察奶栗是否能重新回到面板附近。

## 第二阶段：顶部休息行为（2026-11）
- 主进程增加 `away` / `returning` / `resting` 状态通知；靠近面板目标点约 18px 进入休息状态。
- 在顶部连续停留约 7 秒后，有冷却时间限制地触发既有 `sleep` 动画，避免频繁趴睡。
- 移动、投喂、如厕、拖拽、近期手动互动时不触发顶部自动睡觉。
- 此阶段复用已有 Canvas 睡姿，并非新绘制的 Gen 1 专属透明 PNG 趴睡素材。
- 需要在 Mac 实机验证顶部脚底锚点、窗口重叠、面板靠近屏幕边缘时的站位、休眠唤醒后恢复。
